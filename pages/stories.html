Mockups per Story

S1
Empty State
Home screen when no books exist. Illustration, title, subtitle and CTA button.
S2
Add a Book
FAB opens Add Book form. Title, author, save and validation error state.
S3
Read List
Empty state and scrollable list of books showing title and author.
S4
Book Detail
Tap a book row to open detail screen showing title, author and back button.
S5
Edit Book
Edit button opens pre-filled form. Save updates Book Detail with new values.
S6
Delete Book
Delete button triggers confirm alert. Confirmed deletion removes book and navigates back to list.
S7
Extended Form Fields
Genre, pages, publisher and dates added to Add and Edit forms. Genre shown on book row.
S8
Tab Bar
Read and Wish List tabs with badge counts. Mark as Read toggle determines which tab a book appears in.
S9
Rating
Star rating in Add and Edit forms. Book Detail displays saved rating.
S10
Cover Image
Cover picker in Add and Edit forms. Thumbnail on book row, full cover on Book Detail.
S11
Search
Search bar filters by title and author in real time. Highlights matches, shows no-results state.
S12
Filter Sheet
Bottom sheet with genre chips and author list. Active filters shown as chips on list. Clear All resets.
S13
Sort Sheet
Bottom sheet with 5 sort options, each with asc/desc toggle. Active sort shown on list with label.
