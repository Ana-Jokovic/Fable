Acceptance Criteria

Tap Delete
  • Delete button visible on Book Detail
  • Tapping Delete shows confirm alert
  • Alert shows book title in message
Confirm deletion
  • User taps "Delete" in alert
  • Book is permanently removed
  • User navigated back to Read list
  • Deleted book no longer appears
Cancel deletion
  • User taps "Cancel" in alert
  • No changes are made
  • User remains on Book Detail
Last book deleted

  • Empty state is displayed
