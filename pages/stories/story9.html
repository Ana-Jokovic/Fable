Acceptance Criteria

Toggle OFF
  • Rating field not visible
  • Book saved to Wish List
Toggle ON
  • Rating field appears below toggle
  • 0 stars selected by default
  • Tapping a star fills up to that star
  • Rating saved with the book
Book Detail
  • Saved rating displayed as stars
  • Filled stars gold, empty grey
Edit Book
  • All fields pre-filled
  • Toggle ON, rating pre-filled
  • User can update rating
  • Save Changes persists new rating
