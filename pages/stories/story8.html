Acceptance Criteria

Tab bar
  • Read and Wish List tabs visible
  • Each tab shows book count badge
  • Active tab has gold underline
Mark as Read ON
  • Book saved to Read list
  • Appears in Read tab
  • Not in Wish List tab
  • Read badge count +1
Mark as Read OFF
  • Book saved to Wish List
  • Appears in Wish List tab
  • Not in Read tab
  • Wish List badge count +1
Empty tab
  • Empty state shown on active tab
  • Badge shows 0
