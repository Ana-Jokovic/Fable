Acceptance Criteria

Add cover
  • Cover picker shown at top of form
  • Tapping picker opens photo library
  • Selected image shown as preview
  • Edit badge (✎) visible on preview
  • Tapping preview re-opens picker
Book list
  • Cover shown as thumbnail on row
  • Thumbnail is cropped to fit
  • No cover → placeholder icon shown
Book Detail
  • Cover displayed full-width at top
  • No cover → solid colour placeholder
Out of scope
  • Camera capture
  • Automatic cover fetch by ISBN
  • Cover crop / zoom tool
