Acceptance Criteria

Open sheet
  • Filter button (⊟) visible in search row
  • Tapping it opens Filter Sheet as bottom sheet
  • Genre chips derived from existing books
  • Author list derived from existing books
  • Book count shown next to each author
Apply filters
  • Multiple filters can be selected at once
  • Tapping "Apply Filters" closes sheet
  • Active chips shown below search bar
  • Filter button turns accent colour when active
  • Result count shown above filtered list
Remove filters
  • Tapping ✕ on a chip removes that filter
  • Tapping "Clear All" removes all filters
  • Full list restored after clearing
  • Filter button returns to default style
Out of scope
  • Filter by rating
  • Filter by date range
  • Sort sheet
