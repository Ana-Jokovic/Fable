Acceptance Criteria

Open form
  • User is on home screen
  • Taps FAB "+" button
  • Add Book form opens
  • Nav bar shows "Cancel" and "Add Book" title
Save book
  • Title and Author are filled in
  • User taps "Save Book"
  • Book is saved and appears in the list
  • Form closes
Validation error
  • User taps "Save Book" with empty fields
  • Error shown below each required field
  • Save button is disabled
  • Book is not saved

Note: This story covers Title, Author, Save Book button, Cancel button and required fields label only. No other fields.
