Acceptance Criteria

Open Edit form
  • Edit button visible on Book Detail
  • Tapping Edit opens Edit Book screen
  • Title and authors are pre-filled
Save changes
  • User updates title or authors
  • Taps Save Changes
  • Navigates back to Book Detail
  • Detail shows updated values
Cancel
  • Tapping Cancel discards changes
  • Returns to Book Detail
  • Original values remain intact
Validation
  • Title and author are required
  • Error shown below empty field
  • Changes not saved if invalid
