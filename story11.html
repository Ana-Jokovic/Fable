Acceptance Criteria

Search bar
  • Search bar visible below tab bar
  • Placeholder: "Search by title or author..."
  • Tapping bar activates it with focused style
  • "Cancel" button appears when active
  • Tapping Cancel clears query and dismisses keyboard
Results
  • List filters in real time as user types
  • Matches title and author, case-insensitive
  • Result count shown above list
  • Matching text highlighted in results
  • Only active tab's books are searched
No results
  • Empty state shown with search query in message
  • Suggestion to try a different term
  • FAB remains visible
Out of scope
  • Search history / suggestions
  • Search across both tabs simultaneously
  • Filter and sort
