Acceptance Criteria

Open sheet
  • Sort button (⇅) visible in search row
  • Tapping it opens Sort Sheet as bottom sheet
  • Options: Rating, Title, Date Read, Published Date, Page Count
  • Each option has asc/desc direction toggle
  • Active option highlighted with ✓ and accent colour
Select sort
  • Tapping an option selects it and deselects previous
  • Only one option active at a time
  • Direction toggle updates sort label below option
  • Sheet closes after selection
List feedback
  • Sort button turns accent colour when non-default sort active
  • Sort label bar shows active sort name and direction
  • List order updates immediately after sheet closes
  • Default sort is Date Added, newest first
Out of scope
  • Multi-level sort (sort by two criteria)
  • Filter sheet
  • Persistent sort across app restarts
